# Notes Frontend

A modern, minimalist React app for managing personal notes, following the Ocean Professional theme.

## Quick Start
- Install dependencies: `npm install`
- Run the app: `npm start`
- Open: http://localhost:3000

The app requires no backend and uses localStorage for persistence by default.

## Optional Environment
- `REACT_APP_API_BASE` (or `REACT_APP_BACKEND_URL`) for future backend integration.
If not set, the app uses localStorage.

## Features
- Create, edit, delete notes
- Auto-save with debounced updates
- Search and sort by last updated
- Ocean Professional theme with smooth transitions, rounded corners, and subtle shadows

See `README-NOTES.md` for more details.
